# Screenshots

- `all-basins-desktop.png`: live public NHC data in the authorized Home
  Assistant lab, showing every configured basin, quiet/activity states,
  development outlooks, simultaneous storms, and official imagery.
- `atlantic-single-card.png`: mobile-width, normal non-panel Lovelace placement
  with a card-level Atlantic filter and no active Atlantic storms.
- `atlantic-dashboard.png`: wide Atlantic dashboard example combining the card
  with ordinary Home Assistant heading and entity cards.

The images were reviewed before publication. They contain public NOAA/NHC data
and a generic isolated-lab account only; no production identifiers, private
coordinates, credentials, tokens, or private captures are included.

Future releases should add light-theme, stale-source, active local alert, and
unavailable-image examples when suitable privacy-safe states are available.
